# Blog para Oficinas 2

## Sobre

Esse é um repositório para o blog necessário para a matéria de oficinas do
curso de engenharia eletrônica na UTFPR-Curitiba. Os requisitos desse blog são:
- Uma seção para o 'overview' do projeto;
- Uma seção para a proposta do projeto;
- Uma seção para o cronograma do projeto;
- Uma seção para posts sobre o projeto (um post para cada entregável);
- Uma seção para o relatório final do projeto;
- Uma seção para vídeo(s) do projeto (talvez incluso nos posts?);
- Uma seção para a equipe;

O blog deveria ser atualizado semanalmente.
