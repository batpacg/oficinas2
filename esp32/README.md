## Célula de Carga

### SEN-10245

https://github.com/bogde/HX711/blob/master/examples/HX711_basic_example/HX711_basic_example.ino
https://peppe8o.com/load-cell-with-arduino-uno-using-hx711-amplification/
https://www.mouser.com/en/ProductDetail/SparkFun/SEN-10245?qs=WyAARYrbSnaF3tJl7uQu7A%3D%3D

Trata-se de célula de carga meia ponte. Por isso, tem que medir a resistência
entre os terminais para descobrir o valor das resistência equivalentes
internas. O valor encontrado deve ser usado para montar a outro metade da ponte
a fim de criar A- (a célula porvém apenas A+).
